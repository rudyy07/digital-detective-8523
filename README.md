## Topics Explored

- **Computer Fundamentals:** IPOS cycle (Input, Processing, Output, Storage), hardware vs software classification, and everyday computer-based systems.
- **macOS Terminal & CLI:** Directory navigation, safe file editing (`>` vs `>>`), copying/renaming, command flags (`-l`, `-a`, `-h`), pipes (`|`), and Homebrew inspection.
- **Operating System:** macOS system info, process management and PIDs, storage usage, absolute vs relative paths, and file permissions (`r`, `w`, `x`).
- **Program Execution:** Writing and running a Python 3 script (`hello.py`) and comparing compilers vs interpreters.
- **Numbers & Data:** Manual and Python-verified decimal/binary/hexadecimal conversions, a Python converter script, and ASCII vs UTF-8 text encoding.
- **Git & GitHub:** Staging vs committing, branching (`update-about`), Pull Requests, and a Git command glossary.
- **Computer Networks:** LAN/MAN/WAN, DNS, routers, protocols, packet switching, client-server communication, `ping`, `nslookup`, and `dig`.

## How to Run the Number Converter

From the repository root, change into the Mission 5 folder and run `number_converter.py` with Python 3:

```bash
cd mission-05-numbers-data
python3 number_converter.py
```

When prompted (`Enter a decimal integer: `), type a whole number such as `13`, `25`, or `255` and press Enter to see its binary and hexadecimal values.
