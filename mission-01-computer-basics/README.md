### Task 1.1 — Trace one activity using IPOS

**Chosen activity:** Typing a short study note in VS Code on my Mac and saving it as a text file.

| Stage | What happens in my example? | Hardware / component involved |
|---|---|---|
| Input | I press keys on the keyboard to type letters and use the trackpad to click the Save option (or press Command + S). | Built-in Mac keyboard and trackpad |
| Processing | The processor receives the keystrokes, turns them into characters in memory (RAM), and updates the editor state. | CPU (processor) and RAM (memory) |
| Output | The typed characters and cursor appear on the display right away so I can read and edit my note. | Laptop display (screen) |
| Storage | When I save the file, the operating system writes the note's data permanently to the solid-state drive so it stays available after restarting. | Internal SSD (solid-state drive) |

**How the activity moves from input to output and storage:** First, physical key presses act as input signals sent to the system. The CPU and RAM process those signals into text characters and send them to the screen as output. Finally, when I choose Save, the data in temporary memory (RAM) is written to permanent storage on the SSD so the note is not lost when the editor or computer closes.

## 4. My understanding

Every computer system, whether a laptop or an everyday machine like an ATM, follows the IPOS pattern: it takes input, processes data in memory using a processor, shows output to the user, and stores data when needed. Hardware is the physical equipment you can touch (like a keyboard or SSD), while software is the set of instructions running on that hardware. Software is split into operating system software (which runs the whole computer), application software (which helps users get tasks done), and utility software (which helps monitor or maintain the system).
